# Crawler Archive

Temporary one-month archive for raw pre-match Titan V23 crawler packets used by MODEL_1.

## Storage

- Raw crawler packets are grouped by crawler date.
- Large packet sets may be stored as lossless compressed archives to keep the repository compact.
- `index.json` records the original filenames, SHA-256 checksums, sizes, run IDs, crawler versions, and match indexes.
- These are pre-match source artifacts only. Do not rewrite them with post-match information.

## Coverage

Requested archive window starts at 2026-09-01. The ChatGPT file library currently contains identifiable `football_v23_titan_only_*` packets beginning on 2026-09-05. No matching V23 deep-crawler packet was found for 2026-09-01 through 2026-09-04 during the initial backfill audit.
